# DietBot — Your Personal Diet Assistant

Making healthy eating easier, one conversation at a time! 

**DietBot** is a Python-based chatbot with a simple, interactive web interface built using Gradio. It gives users a place to explore diet and nutrition-related questions through a conversational experience.

I built this project to explore chatbot development and learn how Python can be used to create interactive web applications.

##  What is DietBot?

-  **Chat-based experience** — interact with the bot through a simple interface.
-  **Diet-focused conversations** — explore diet and nutrition-related topics.
-  **Easy-to-use interface** — powered by Gradio.
-  **Python project** — built with Python and Gradio.

##  Built With

| Technology | Purpose |
|---|---|
| Python | Application logic |
| Gradio | Web interface for the chatbot |

##  Run It Locally

Want to try DietBot on your computer? Follow these steps.

**1. Clone this repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd DietBot
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the URL of this repository.

**2. Install the required package**

```bash
pip install -r requirements.txt
```

**3. Start the chatbot**

```bash
python diet_chatbot_gradio.py
```

Open the local URL shown in your terminal to interact with DietBot.
